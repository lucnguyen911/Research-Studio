WHAT IS RESEARCH STUDIO?

A quieter place
to do the groundwork.

Bring source research, competitor tracking and your own thinking into one local workspace.

Research Studio is a Windows desktop-oriented application with a browser-based interface and a local backend. It is designed for individual YouTube creators researching one channel or several topics. The current release runs locally from source; a packaged desktop installer is not yet provided.

DISCOVERY

Explore public YouTube data

Search videos and channels, request most-popular listings by region and category, and revisit cached search sessions while valid.

COMPETITORS

Keep relevant channels in view

Link competitor channels to projects, refresh their uploads, and inspect source video and channel metadata with collection timestamps.

RESEARCH

Follow keywords and feeds

Save project keywords and scan YouTube results. Read public RSS / Atom feeds, bookmark articles, and explore phrases from RSS content.

IDEAS

Give each idea a home

Create ideas with notes and tags, link them to multiple projects, and track project-specific angles, priorities and production status.

STANDARD MODE

Read the source, add your judgment

Filter and sort raw metadata, mark videos for research manually, and view timestamped raw-count snapshots when enough observations exist. No VPH or outlier multiplier is offered.

WORKSPACE

Manage your local work

Export project research as JSON, create and restore user backups, manage storage locations, and clear cached YouTube data from Settings.

HOW IT WORKS

Find a signal. Keep the context.

Set up your workspace

Create a project for a channel or topic. Read the legal disclosures and supply your own YouTube Data API key to enable YouTube requests.

Gather source material

Search public metadata, follow competitor uploads, and add RSS feeds. Automatic refresh is configurable and runs while the local backend is open.

Develop your direction

Save ideas, write an original angle, and organize your next steps. Research Studio supports your decisions; it does not promise views or growth.

LOCAL-FIRST ARCHITECTURE

Your workspace
lives on your PC.

Research is stored in a local SQLite database. The interface talks to a local FastAPI backend bound to a loopback address. No developer-operated cloud account, research upload service or telemetry is implemented.

Local does not mean disconnected.

YouTube API requests go to Google, feeds go to their publishers, and displayed thumbnails may load from external image servers. Those services receive connection information.

Optional backup folders can be managed by your own synchronization software. Read the privacy policy for retention limits, backup exceptions and deletion steps.

YOUTUBE API INTEGRATION

Transparent about the source.
Careful about the scope.

Research Studio uses YouTube Data API Services to retrieve public video and channel information. YouTube is the source of applicable metadata and raw statistics. The current implementation uses an API key, without Google OAuth, private account analytics or upload access.

YouTube-related functionality is subject to the YouTube Terms of Service and applicable YouTube API Developer Policies.

PROPOSED · REVIEW PENDING

Advanced analytics

Research Studio is preparing to request approval for Views Per Hour (VPH), recent VPH from timestamped snapshots, outlier performance analysis, channel-relative comparisons, and custom content research scores where permitted.

These capabilities are proposed, unavailable in the current Standard Mode, and not represented as authorized. Any future implementation depends on YouTube confirming the permitted scope. Extended API-data retention is not approved.

DATA PRIVACY AND SECURITY

Clear controls.
Honest limitations.

The API key is protected at rest with Windows DPAPI for the current Windows user. Other workspace data is not encrypted by the application. Settings includes key removal, consent revocation and a separate cached YouTube data deletion control.

Live API metadata uses a default 30-day expiry. Backup and copied-title retention gaps remain under review; publishing this website does not establish full YouTube API compliance.
